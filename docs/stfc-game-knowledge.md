## 1. Game Overview

Star Trek Fleet Command (STFC) is a free-to-play mobile MMO strategy game set
in the Kelvin-timeline Star Trek universe (developed by Digit Game Studios,
published by Scopely). Players build and manage a space station, grow a fleet,
collect officers, and explore a persistent open galaxy while cooperating (or
competing) with other players.

**Key pillars:**
- Station building and resource management
- Fleet construction and combat
- Officer collection and crew optimization
- Faction reputation and progression
- Alliance co-op (armadas, territory capture, events)

---

## 2. Core Game Loop

1. **Collect resources** — mine raw materials, complete missions, claim daily
   gifts, and redeem promo codes.
2. **Upgrade the station** — advance the Operations (Ops) level, which is the
   gate to all other progression.
3. **Build and upgrade ships** — gather blueprints, build ships in the
   Shipyard, and upgrade them for better combat and mining power.
4. **Complete missions** — story, daily, and faction missions award officers,
   ship blueprints, resources, and faction reputation.
5. **Participate in events** — rotating daily, weekly, and monthly events
   reward rare officers, ship parts, and exclusive items.
6. **Alliance play** — armadas, territory capture, and alliance events require
   coordinated group effort.

## 3. Operations Level & Buildings

**Operations (Ops)** is the master progression gate. Every other building has
a maximum level equal to or below the current Ops level.

### Interior buildings

| Building | Purpose |
|---|---|
| **Operations** | Master gate; increases max level for all other buildings |
| **Academy** | Raises officer capacity and officer stat caps |
| **R&D Department** | Unlocks research trees |
| **Shipyard** | Builds and upgrades ships |
| **Parsteel/Tritanium/Dilithium Warehouse** | Sets resource storage cap |
| **Parsteel/Tritanium/Dilithium Vault** | Protects resources from raiding |
| **Parsteel/Tritanium/Dilithium Generator** | Produces resources passively |
| **Refinery** | Converts raw ore/gas/crystal into processed materials |
| **Independent Archives** *(Ops 16+, added late 2024)* | Reduces grind for daily tasks; streamlines key game loops |
| **Starfleet Academy Remote Campus** *(Ops 61+, Update 90)* | New late-game progression building tied to the Academy loop |

### Exterior buildings

| Building | Purpose |
|---|---|
| **Defense Platform** | Automates base defense; upgrades increase firepower |
| **Drydock** | Each drydock provides one active ship slot; upgrade for more fleet capacity |

### Progression milestones

For specific camping opinions, refinery unlocks and rare G4 gas sourcing, see
the [Ops progression and G4 gas reference](./stfc-knowledge/ops-progression/README.md).

| Ops range | Focus |
|---|---|
| 1–14 | Base management, resource flow, first ships |
| 15–19 | PvP unlocks, better mining systems, higher-tier ships |
| 20–25 | Elite research, faction alignment, resource independence |
| 26–44 | Faction ships, mid-game research specialization, PvP tactics |
| 45–60 | G4/G5 ships, late-game research, alliance territory play |
| 61+ | Remote Campus, G5 scrapping (Update 90), endgame systems |

## 4. Resources

| Resource | Use |
|---|---|
| **Parsteel** | Most common; used for almost all building and ship upgrades |
| **Tritanium** | Scarcer; ships and bulkheads |
| **Dilithium** | Rarest; high-end ships and buildings |
| **Raw Ore / Gas / Crystal** | Mined in the galaxy; refined into processed materials |
| **Faction Credits** | Earned via faction missions; spent in faction stores for exclusive ships, blueprints, and officers |

> **Tip:** Resources above vault protection thresholds can be raided by other
> players. Always spend excess on upgrades or store them in vaults.

## 5. Ships

Ships are divided into **grades** (G1–G5, with higher grades planned) and
**types**:

- **Explorer** — strong against Battleships
- **Interceptor** — strong against Explorers
- **Battleship** — strong against Interceptors
- **Survey / Mining** — optimized for resource gathering, not combat

The combat triangle: **Explorer → Battleship → Interceptor → Explorer**

### Key ships by grade

| Grade | Notable ships |
|---|---|
| G1 | Realta (Explorer), Orion Corvette (Battleship), ECS Fortunate (Survey), Phindra (Interceptor) |
| G2 | Talla (Battleship), Jellyfish (Explorer), Turas (Explorer), Envoy (Survey) |
| G3 | USS Franklin (Explorer), Vi'dar (Interceptor), D'Vor (Survey), North Star (Survey), Bortas (Battleship), D3 Class (Interceptor), Centurion (Explorer), Kumari (Battleship), Mayflower (Explorer), Saladin (Interceptor), Horizon (Survey), B'Rel (Explorer), D4 Class (Interceptor), Intrepid (Battleship), Augur (Battleship), Enterprise (Explorer), Stella (Battleship), Amalgam (Survey) |
| G4 | Corvus (Explorer), ISS Jellyfish (Explorer), Sarcophagus (Battleship), Mantis (Battleship), USS Franklin-A (Explorer), faction-specific endgame ships |
| G5 | D'deridex (Battleship), Borg Sphere (Battleship), Nova (Survey), various faction capital ships; G5 Scrapping introduced in Update 90 |

**Key ship stats:** Attack, Defense, Health, Cargo, Protected Cargo, Warp
Range, Impulse Speed.

For full, up-to-date stats and unlock requirements see
<https://stfc.space/ships/> (community database) or the official database at
<https://startrekfleetcommand.com/star-trek-fleet-command-database/>.

## 6. Officers

Officers are collected through recruits, events, and missions. They are
assigned to ships and provide combat or mining bonuses.

### Officer slots

- **Captain** — activates the Captain's Maneuver (special ability)
- **Bridge officers** — Officer Ability always active on the bridge
- **Below Deck (BDA)** — specialist buffs for mining, warp, or Isolytic damage

### Key synergy groups

| Group | Notable officers | Best use |
|---|---|---|
| Enterprise Crew | Kirk, Spock, McCoy, Uhura, Sulu | Tank/defense; Morale stacking |
| Klingon Patriots | Gorkon, Azetbur, Kang, Mara, Worf | PvP raiding; crit + Hull Breach |
| Romulan | Nero, Decius, Livis, Marcellus | PvE hostile grinding |
| Mining Crew | Barot, T'Pring, Stonn | Max mining rate |
| Hostile Grinding (early) | Pike (captain), Moreau, Chen | Mitigation; crit reduction for farming |
| Symbiosis Group (Update 71) | Masriad Vael, Byr Ch'Kelrer, Dajash Tolra, Toli | Armada/entity loot; crit damage |

> **Crew-building tip:** Match officers from the same synergy group for bonus
> stats. Don't mix mining crews into combat roles.

## 7. Factions & Reputation

The three primary factions are **Federation**, **Klingon**, and **Romulan**.
Each has a reputation ladder, daily missions, a faction store, and exclusive
ships and officers.

### Reputation tiers (approximate thresholds)

| Tier | Points | Unlocks |
|---|---|---|
| Neutral | 0 | Basic faction store, recruit tokens |
| Friendly | 100,000 | Rare ship blueprints |
| Like | 1,000,000 | Enhanced daily rewards, mid-tier ships |
| Trusted | 2,000,000 | Officer recruiting packs |
| Respected | 3,000,000 | Advanced faction ships |
| Celebrated | 10,000,000 | Best officers, endgame ships; rival faction progress locks |
| Dignitary+ | varies | Maximum rewards, event eligibility, cosmetic unlocks |

**Faction lock:** Once you reach Celebrated with one faction, your rep with
rival factions can no longer increase. Plan your faction path carefully.

### Faction-exclusive rewards

| Faction | Exclusive ships | Notable officers |
|---|---|---|
| Federation | USS Franklin, USS Enterprise, USS Newton | Kirk, Spock, McCoy, Sulu |
| Klingon | B'Rel, D4, Vor'cha | Kang, Gorkon, Mara, Kuron |
| Romulan | D'Vor, Gladius, Augur, Valdore | Decius, Nero, Livis |

## 8. Research

Research is conducted in the **R&D Department** and provides permanent stat
boosts across four trees:

| Tree | Examples of bonuses |
|---|---|
| **Combat** | Ship attack/defense/health, crit chance, armor piercing |
| **Mining** | Mining speed, protected cargo, resource yields |
| **Galaxy** | Warp range, system access, exocomp efficiency |
| **Station** | Base defense, building-upgrade cost reduction |

Research prerequisites typically require a minimum Ops level and R&D
Department level. Prioritize Galaxy and Combat trees early; Station and Mining
for longer-term efficiency.

## 9. Alliance Play

- **Armadas** — cooperative PvE battles against powerful armada targets;
  requires armada directives (special item). Rewards are exclusive officer
  shards and ship parts.
- **Territory Capture** — alliances compete to control star systems for
  resource bonuses and prestige.
- **Alliance Events** — rotating challenges where coordinated contribution
  earns alliance-wide rewards.
- **Alliance Roles** — Leader, Officer, Member; higher roles can set alliance
  rules and manage territory.

## 10. Web Store & Gift Redemption

The STFC web store is at <https://store.startrekfleetcommand.com/> (or
accessed in-game via the Gifts icon).

### Gift types

- **Daily Login Bonuses** — claimable once per day via the web store or
  in-game mail.
- **Event & Promotional Gifts** — time-limited bundles released alongside
  patches, streams, or community milestones.
- **Promo Codes** — universal or targeted codes shared on official social
  channels, the website, and community events. Codes can be level-gated (e.g.,
  Ops 10+, 20+, 38+, 40+, 51+, 55+).

### Redemption API endpoints (used by this tool)

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/auth/me` | Verify JWT is valid; identify the player |
| `GET` | `/offers/gifts?available=true` | List claimable gifts |
| `POST` | `/offers/gifts/claim` | Claim a specific gift (`bundleId`) |
| `POST` | `/redeem/claim` | Submit a promo code (`promo_code`) |

All endpoints are relative to `https://cdn-nv3-webstore-api.startrek.digitgaming.com/api/v2`
and require a bearer token in the `Authorization` header.

### Outcome vocabulary

| Outcome | Meaning |
|---|---|
| `CLAIMED` | Gift or code successfully redeemed |
| `TOKEN_EXPIRED` | JWT's `exp` claim is in the past |
| `CODE_ALREADY_USED` | Promo code redeemed previously on this account |
| `ALREADY_CLAIMED` | Gift bundle already claimed (404 + "Bundle not available") |
| `UNKNOWN_RESULT` | Unexpected API response (schema drift or new status) |
