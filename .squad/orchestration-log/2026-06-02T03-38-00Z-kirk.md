## Architecture summary

```
User → Discord POST → CF Worker → verify sig + defer → GH dispatch
  ↓
GH `discord-command-handler.yml` → run command → PATCH follow-up message
```

Worker is stateless (~100 LoC), business logic stays in GHA. Secrets: DISCORD_PUBLIC_KEY (CF), DISCORD_BOT_TOKEN (GHA, exists), GH_DISPATCH_TOKEN (CF, new PAT), CLOUDFLARE_API_TOKEN (GHA, new), CLOUDFLARE_ACCOUNT_ID (GHA, new).
