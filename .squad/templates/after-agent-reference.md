# After Agent Reference

### After Agent Work

Collect the results of requested work, report failures and material outcomes, and
route necessary follow-up to the accountable owner. Do not automatically spawn
support agents, create session logs, or manufacture records.

Do not merge decisions or rewrite the canonical ledger; do not delete inbox entries.
Linked worktrees share state refs, and the pinned runtime has no verified
cross-process serialization for the complete merge-and-delete operation. Retain
inbox entries and report this limitation. An explicitly requested Scribe may inspect
decisions and pending proposals read-only using its charter.

If Ralph is explicitly active, follow the authorized monitoring instructions.
