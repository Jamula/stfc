## Source of Truth Hierarchy

> **State backend note:** Entries marked "Derived / append-only" are **mutable state** — agents access them with runtime state tools (`squad_state_read`, `squad_state_write`, `squad_state_append`, `squad_state_delete`, `squad_state_list`). The runtime decides whether the configured backend stores them on disk, git-native state, or an external provider. Entries marked "Authoritative" are **static configuration** and always live on disk regardless of backend. The decisions recorded in the decision ledger are canonical and authoritative; the ledger file itself is derived, mutable, append-only state accessed through the configured backend.
>
> **Decision ledger key:** The logical state-tool key is `decisions.md`. The canonical local path in this repository is `.squad/decisions/decisions.md`; other backends need not store it at that path.
